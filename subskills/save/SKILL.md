# Save — 会话记忆归档

> `super-memory` 的 save 子命令。会话结束或完成重要交付时，把本次产生的有价值信息写进**当前 agent 的记忆库**并更新索引。
> 本文件由父级用 Read 加载，不是独立 skill；工具授权看父级 frontmatter。

## 什么时候走

- 用户说"保存记忆""save memory""总结一下这次会话""先这样""就这些""结束了"
- 完成了一个重要交付物
- 用户说"同步一下"但没提到洁癖审查级别 → 按 save 快速归档，不必起 neat

**不算 save 的**：让我摘要一段网页或 PR 内容（那是内容总结，不写盘）；只改了代码没产生新事实；用户说的"记一下"是指记进 TODO/issue 而不是记忆库。

## 流程

### 1. 定位记忆库

按 `../../references/memory-addressing.md` 的四层（宿主自述 → 规则文件 → 通用探测 → 兜底）确定用户级与项目级两个目录，并把探测结果打印出来。没探测到就用项目根 `memory/` 并在输出里声明。

### 2. 读现状

- 目标目录的 `MEMORY.md` 索引 + 本次要碰的条目文件
- `.learnings/` 三个聚合文件，确认 capture 阶段已记的东西

### 3. 判断该不该写、写到哪级

只问一句：**换一个项目这条还成立吗？** 成立 → 用户级；只在本项目成立 → 项目级。完整分流表见 `../../references/memory-addressing.md` 第二节。

| 会话里出现的东西 | 去处 |
|---|---|
| 用户纠正的做法、长期偏好、协作习惯 | 用户级（多数是 feedback 类） |
| 用户角色、技术栈背景 | 用户级 |
| 本项目的事实、决策、进度、约束 | 项目级 |
| 与本项目绑定的外部资源地址 | 项目级 |
| 与项目无关的工具通用用法 | 用户级 |
| 命令失败、更好的做法 | 已由 capture 落在 `.learnings/`，此处只确认已记，不重复写 |

### 4. 写入

- **先 grep 索引**：命中同类条目 → Edit 那条（含更新它的 description），不新建。
- **格式照现存条目**：读目标目录 1–2 个现有文件，抄它的 frontmatter 字段与索引行格式，不自创。
- 新建时：文件名 kebab-case、`name` 与文件名一致、`description` 写成将来能凭它判断相关性的具体一句话；frontmatter 默认带 `last_verified: <写入日期>`（便于 neat 超龄体检），若目标目录现存条目都不用此字段则跟现存格式不强加。
- 每条正文含：事实本身 + **Why**（哪次踩的、什么约束）+ **How to apply**（什么时候生效）。
- 索引追加一行 `- [标题](文件.md) — 一行钩子`；索引只放指针。

### 5. 验证（不许跳过）

写盘后实测，不靠记忆：

```bash
ls -la <目标目录>                      # 文件真在里面
grep -c "^\- \[" <目标目录>/MEMORY.md   # 索引行数
grep -rE "今天|昨天|刚刚|最近|上周" <新建或修改的条目> || echo "相对时间 0 命中"
```

然后**回读**新建/修改的条目，确认 frontmatter 完整、正文没被截断、没有相对时间残留。

## 输出

```
记忆已保存

记忆位：<探测到的目录>（探测方式：规则文件 / 宿主探测 / 兜底）
新增：<文件> — 一句话
修改：<文件> — 改了什么
索引：MEMORY.md 现有 N 条（写前实测）
未写：<候选项> — 为什么没写（重复 / 归 .learnings / 只在本轮有用）
```

写失败、目录不存在、grep 命中 0 都要照实写出来，不许用"已保存"糊过去。

## 注意

- **必须真的写盘**——描述"我会怎么存"不算完成。
- **宁多勿漏**：用户纠正过的内容漏掉一次，下次就会重犯。
- **主动**：交付完成后不必等用户提醒。
- **绝对时间**：`YYYY-MM-DD`，永不写"今天/昨天/最近"。
- **不写密钥**：任何 token、私钥、环境变量值都不进记忆库。
