把开发过程，
整理成一份可交接的卷宗。

AI 会话结束即失忆，交接靠口口相传，散落的记忆文档越积越乱。super-memory 用一套结构化的记忆生命周期回答三个问题：怎么存、怎么交、怎么读—— 纯 Markdown 文件驱动，无外部服务、无向量库。

一

要解决的问题

WHY

AI 编码工具的默认缺陷是失忆：会话结束，错误与纠正随之清零；接手一个项目，靠翻聊天记录和猜。 更糟的是，各工具自发生成的记忆文档散落在 .ai/、.learnings/、memory/、 docs/ 各处——命名五花八门（HANDOFF、HANDOVER、交接文档、项目记忆……），同一职能五六份并存，新会话接手时读到的往往还是十天前的过期快照。

super-memory 把记忆当作一个有生命周期的正式资产来管理：实时捕获、结构化交接、接手时探测与核验、 里程碑时全面清理。它不假设宿主、不假设目录、不假设文件名——一切现场探测，然后按角色归位。

本页的所有规则，都来自真实项目接手时踩过的坑——包括两次被用户当场纠正的误判。

二

三层记忆模型

STRUCTURE

每条知识有唯一的家，其他位置只放索引——散落与漂移从结构上被禁止。

  • 壹
    短期 · 会话上下文

    临时调试、中间尝试——不落盘，归宿是对话本身。

  • 贰
    中期 · .ai/HANDOFF.md

    进度、断点、下一步。每次追加同步刷新头部指针，进度三问（到哪了/停在哪/下一步）不看全文即可回答。

  • 叁
    长期 · .ai/knowledge/

    跨模块通用的解法、决策、模式。只收已验证事实，置信度用 [V][W][Q][R][F] 字母码标注。

  • 肆
    宿主记忆库 · 跨项目

    用户的偏好、协作习惯、背景——跟着人走，不跟着仓库走。

  • 伍
    暂存 · .learnings/

    错误与纠正的实时捕获，成熟后升档，随时待清理。

三

六个子命令

LIFECYCLE

覆盖「存 → 交 → 读 → 清 → 提」的记忆全生命周期。装好后说自然语言即可触发。

  • capture
    实时捕获

    错误、用户纠正、知识过时、更好做法——先查重再写入，避免同一课记两遍。

  • handoff
    会话交接（写入端）

    七条写入质量硬要求：精准锚定、根因导向、进度可扫读、追加式头部指针……

  • intake
    接手与阅读

    探测散落记忆文档 → 按角色分类读 → 全面分析三层次 → 新鲜度三角核验 → 接手简报。新项目则初始化骨架。

  • save
    跨项目归档

    偏好与习惯进宿主记忆库；用户级 / 项目级两级分流，判不准放项目级。

  • neat
    洁癖同步

    里程碑时全面审查：尺寸体检先行，变更矩阵查波及面，删除一律先隔离。

  • promote
    提炼规则

    反复出现的学习提炼成两句话内的硬规则，写进项目规则文件。

四

核心机制

MECHANISMS

不自创概念——每一条都从经过验证的开源方案移植，再用真实项目 dogfood 校准。

机制做什么借鉴
巩固四操作写入前查相似旧条目，ADD / UPDATE / SUPERSEDE / NOOP 四选一并写明判定；删除一律降级留痕mem0
Related 互链知识条目双向链接，入库前检索相关旧条目并演化更新A-Mem
双时间戳「生效」与「记录」分离——结论还成立吗看生效，当时是否最新认知看记录Graphiti
记忆体检索引断链 / 重复条目 / 非法置信度码 / 超龄未验证，四项一条命令可判Letta /doctor
探测式寻址宿主自述 → 规则文件 → glob 通用探测 → 兜底，多命中按裁决顺序；8 类宿主形态实测自研
新鲜度三角记忆自述的最后更新 ↔ git HEAD 日期 ↔ 源码 mtime，对不齐即报记忆漂移dogfood 实录

检索路线刻意保持纯文件：grep + frontmatter + 索引。Claude Code 官方 memory tool、Cline memory bank、Letta MemFS 均验证过这条路线对 agent 场景足够——而且每一份记忆人都能直接打开读。

五

安装

INSTALL
# 落到 .agents（按宿主换 ~/.zcode/skills 或 ~/.claude/skills）
mkdir -p ~/.agents/skills/super-memory
curl -L https://github.com/harryopo/super-memory/archive/refs/heads/main.tar.gz \
  | tar -xz -C ~/.agents/skills/super-memory --strip-components=1

# 自检应全绿
python scripts/verify.py

之后说自然语言即可触发：「保存记忆」「接手这个项目」「继续上次到哪了」「整理一下文档和记忆」「新项目初始化」。
