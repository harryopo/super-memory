三层记忆模型

每条知识有唯一的家，其他位置只放索引——散落与漂移从结构上被禁止。

短期 · 会话上下文临时调试、中间尝试，不落盘
→
中期 · .ai/HANDOFF.md进度、断点、下一步，每会话必更
→
长期 · .ai/knowledge/跨模块解法、决策、模式
→
宿主记忆库跨项目偏好与习惯

另有 .learnings/ 实时暂存错误与纠正；成熟学习提炼进项目规则文件。

六个子命令

覆盖「存 → 交 → 读 → 清 → 提」的记忆全生命周期，说自然语言即可触发。

capture · 实时捕获

错误、用户纠正、知识过时、更好做法——结构化落盘，先查重再写入。

handoff · 会话交接

写满写实的交接文档：进度三问（到哪了/停在哪/下一步）不看全文即可回答。

intake · 接手与阅读

探测散落的记忆文档（中文名/日期变体/多容器）→ 按角色读 → 代码真值核验 → 接手简报。

save · 跨项目归档

偏好与习惯进宿主记忆库，两级分流，格式贴现存条目。

neat · 洁癖同步

里程碑时对文档与记忆全面审查：尺寸体检、变更矩阵、删除先隔离。

promote · 提炼规则

反复出现的学习提炼成两句话内的硬规则，写进项目规则文件。

核心机制

不是自创概念——每一条都从经过验证的开源方案移植，再用真实项目 dogfood 校准。

巩固四操作

写入前先查相似旧条目，ADD / UPDATE / SUPERSEDE / NOOP 四选一并写明判定；删除一律降级留痕，记忆不漂移。

双时间戳

记忆体检

索引断链、重复条目、非法置信度码、超龄未验证——四项一条命令可判的机械检查。

Letta /doctor

探测式寻址

不硬编码宿主路径：宿主自述 → 规则文件 → glob 通用探测 → 兜底，多命中按裁决顺序。Qoder / ZCode / Trae / Codex 等 8 类宿主实测。

自研

新鲜度三角

记忆自述的最后更新 ↔ git HEAD 日期 ↔ 源码 mtime——三者对不齐即报记忆漂移。

dogfood 实录

安装

一个 tar 包，落进宿主的 skills 目录即可。

# 落到 .agents（按宿主换 ~/.zcode/skills 或 ~/.claude/skills）
mkdir -p ~/.agents/skills/super-memory
curl -L https://github.com/harryopo/super-memory/archive/refs/heads/main.tar.gz \
  | tar -xz -C ~/.agents/skills/super-memory --strip-components=1

# 自检应全绿
python scripts/verify.py

之后说自然语言即可触发：「保存记忆」「接手这个项目」「继续上次到哪了」「整理一下文档和记忆」「新项目初始化」。

为什么纯 Markdown

无向量库、无常驻服务、无构建链——grep + frontmatter + 索引对 agent 的检索场景已经足够，而且每一份记忆人都能直接打开读。

Claude Code 官方 memory tool、Cline memory bank、Letta MemFS 均为纯文件路线；super-memory 在此之上补齐了生命周期管理与质量纪律。
