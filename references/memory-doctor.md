# 记忆体检（memory-doctor）

neat 第 1b 步用。五项机械检查，每项一条命令可判，**每项都要贴实测输出**；0 命中也要报，并分辨"确实没有"还是"格式没对上"。命中项按「处置路由」处理。

## 检查一：索引断链

```bash
grep -oE "\(([^)]+\.md)\)" <记忆位>/MEMORY.md | tr -d "() \r" | while read f; do
  [ -f "<记忆位>/$f" ] || echo "断链 $f"
done
```

处置：索引行指向的文件不存在 → 查隔离区/改名记录；确属死链 → 移除该索引行（属删除索引行，不需第 2.5 步——索引只放指针，不是内容）。Windows 下注意 CRLF（`tr -d '\r'`）。

## 检查二：重复条目

```bash
grep -rin "<主题关键词>" <记忆位>/*.md <记忆位>/MEMORY.md
```

同主题关键词命中 ≥ 2 条相似条目 → 列出对照，按**巩固四操作**合并：knowledge 条目 SUPERSEDE 原地留档；agent 记忆库合并出的废弃侧走第 2.5 步用户确认后隔离。

## 检查三：置信度码合法性

```bash
grep -rnoE "\[[A-Z]{1,3}\]" <记忆位> .ai/knowledge/ 2>/dev/null | grep -vE "\[(V|W|Q|R|F)\]"
```

出现五码之外的字母码（如 `[X]`、`[OK]`）→ 列出并修正为五码之一或 `[已失效]`。可直接修（不改历史内容，只修标记）。

## 检查四：超龄未验证

```bash
grep -rn "last_verified" <记忆位>
```

逐条比对日期：`last_verified` 早于当日 90 天前 → 列出"建议重验或降级"+ 重验方式，**不代判、不删除、不标失效**；本轮无法重验的列入「未处理」。

## 检查五：锚点活性抽查（防引用腐烂）

```bash
grep -rhoE "`[^\`]+:\d+`" .ai/knowledge/ .ai/HANDOFF.md 2>/dev/null | sort -u | head -10
```

从条目「锚点」字段抽样 3–5 个 `path:行号`：`ls`/`grep` 验证文件存在、符号（函数/变量名）仍在。**文件没了或符号消失 → 该条置信度降一级并注明复查日期**（锚点会腐烂，这是设计预期，降级不是惩罚）。抽查即可，不要求全量。

## 处置路由总表

| 发现 | 处置 | 是否需确认 |
|---|---|---|
| 索引死链 | 移除索引行 | 否 |
| 重复条目 | 四操作合并：knowledge 条目 SUPERSEDE 原地留档（不隔离）；agent 记忆库合并出的废弃侧走 2.5 隔离 | knowledge=否；记忆库涉隔离=是 |
| 非法置信度码 | 修正为五码或 [已失效] | 否 |
| 超龄未验证 | 列出提示，列入未处理 | 不动文件 |
| 锚点失效（抽查） | 该条置信度降一级 + 注明复查日期 | 否（降级非惩罚） |
