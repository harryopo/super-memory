# 文档模板（六件）

> `doc-system.md` 的配套模板。新建时用整份；已有文件只补缺失节，保留原编排、不重排。
> 每个模板的占位约定：`<…>` 必填占位，`（待填）` 允许留空，`> 最后核验` 行必须存在。

## 模板 4 · DOC-INDEX.md

```markdown
# 文档索引

> 最后核验：YYYY-MM-DD · 权威层级：代码 > 规则文件 > `.ai/` > `docs/` > `归档`
> ⚠ mtime 不可信：加横幅/改格式会 touch 文件，判断新鲜度看本表「内容日期」。

## 状态图例
| 状态 | 含义 |
|---|---|
| 现役准绳 | 当前唯一权威，冲突以它为准 |
| 活文档 | 持续维护，内容有效 |
| 停更 | 不再维护，仅供历史参考（顶部必须有横幅） |
| 历史快照 | 某一时点的记录，不可作为现状 |
| 索引元文档 | 只做导航，不含事实 |

## 文档清单
| 路径 | 状态 | 内容日期 | 说明 |
|---|---|---|---|
| `.ai/HANDOFF.md` | 现役准绳 | YYYY-MM-DD | 交接与状态 |
| `docs/xxx.md` | 停更 | YYYY-MM-DD | 已被 YYY 取代，顶部有横幅 |
```

**停更横幅格式**（写在文件第一行）：
```markdown
> ⚠ **已停更**（YYYY-MM-DD）：本文最后更新 YYYY-MM-DD，已被 `<新文件>` 取代。仅作历史参考，勿据此判断现状。
```

## 模板 5 · ROADMAP.md（追加式）

```markdown
# ROADMAP

> **最新节为准**：本文件按版本/阶段追加，只读最后一节；更早的节是历史记录。
> 当前指向：§<最新节号>

## §N · YYYY-MM-DD · <版本/阶段名>
- 目标：<…>
- 范围：<做什么 / 不做什么>
- 里程碑：<日期 + 判据>
- 风险：<…>

---
（历史节保留，不删除、不改写）
```

**与 dev-state 的分工**：ROADMAP 管"计划与里程碑"；dev-state 管"实际发生了什么"（追加编号，只读最新节）。

## 模板 6 · TASKS.md

```markdown

## 看板
| ID | 任务 | 状态 | 优先级 | 依赖 | 阻塞原因 | 验收证据 |
|---|---|---|---|---|---|---|

## 速览
- 进行中：<…>
```

**任务 ID 规则**：`T-NNN` 顺序递增，不复用已关闭编号。
