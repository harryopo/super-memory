# 同步完成摘要模板

neat 第五步用。在所有修改做完之后才写，之前写等于给自己挖坑。只列有实际变更的条目，没改的不写。

```markdown
## 同步完成

记忆位：<探测方式> → <用户级目录> / <项目级目录>

### 记忆变更
- 更新：<文件> — 为什么
- 新增：<文件> — 一句话
- 隔离：<文件> → `.tmp/neat-quarantine/<日期>/<原路径>` — 原因（经用户确认，审查报告 <路径>）
- 合并：<文件A> + <文件B> → <文件A> — 重复点

### 文档变更（按项目分组，每组列全改动文件）
- <项目 A>/CLAUDE.md — 改了什么
- <项目 A>/docs/integration-guide.md — 改了什么
- <项目 B>/docs/<xxx>.md — 改了什么

### 尺寸
- CLAUDE.md：改前 N 行 → 改后 M 行（净涨幅 ≤ 30 才算过关）
- 单条 memory：最长 K 行
- 各 SKILL.md 正文体积（若本轮动了 skill）

### 扫描实况（照实报）
- 待处理条目：N 条 / 无命中（原因：确实没有 / 路径没对上）
- 相对时间残留：grep 结果 0 处 / 仍有 X 处待处理

### 未处理
- <项> — 为什么没处理（需用户判断 / 需外部信息 / 属在制品不宜动）
```
